# 📺 Rick&Morty
**Rick&Morty** es una aplicación sencilla desarrollada en UIKit que lista los personajes y episodios de la serie *Rick and Morty* usando la [Rick and Morty API](https://rickandmortyapi.com/).

## Tecnologías utilizadas
- **UIKit**: Para construir la interfaz
- **Async/Await**: Para concurrencia y asincronia
